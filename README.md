# Plex Scripts

Python utilities for managing Plex libraries

## Usage

1. Install dependencies using `pip install -r requirements.txt`
2. Copy `example.config.toml` to `config.toml`, and set your Plex URL and token

## Scripts

- `date_added.py` - set item dates from original release dates
- `missing_date.py` - list items missing original release dates
- `refresh_artwork.py` - refresh library artwork
- `export_history.py` - export watch history to `history.json` file
